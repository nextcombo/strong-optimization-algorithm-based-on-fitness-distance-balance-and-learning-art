# Strong Optimization Algorithm Based on Fitness-Distance Balance and Learning Artificial Bee Colony (Matlab Code Implementation)

FDB-TLABC is a robust optimization algorithm based on fitness-distance balance and learning-based artificial bee colony. 
The Teaching Learning Based Artificial Bee Colony (TLABC) is a hybrid metaheuristic search algorithm based on mixed populations. It combines the development of teaching-learning based optimization (TLBO) with the exploration of artificial bee colony (ABC). By integrating these two natural inspired group intelligent algorithms, a robust method for solving global optimization problems is proposed. However, as with other population-based algorithms, effectively simulating the selection process is a significant challenge when using the TLABC method. Fitness-Distance Balance (FDB) is a recently developed powerful method that can effectively mimic the selection process in nature. In this study, the three stages of the TLABC algorithm were redesigned using the FDB method. Through this approach, an FDB-TLABC algorithm with more effective natural simulation and strong search performance was developed. To investigate the development, exploration, and balance search capabilities of the proposed algorithm, it was tested on standard and complex benchmark test suites (classical, IEEE CEC 2014, IEEE CEC 2017, and IEEE CEC 2020). To verify the performance of the proposed FDB-TLABC in global optimization problems and photovoltaic parameter estimation problems (a real-world engineering problem under constraints), comprehensive and qualified experimental research was conducted according to the IEEE CEC standards. Statistical analysis results confirmed that compared to other optimization methods, the proposed FDB-TLABC provides the best optimal solution and produces better performance.
